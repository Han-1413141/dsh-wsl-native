# 工作区与跨环境交接

适用于 dsh-wsl-native 0.6.0、DeepSeek Harness 0.2.0-rc.2。Windows 和 WSL 使用同一个侧栏，WSL 工作区带小型 `WSL` 标志。

## 新建工作区和对话

侧栏顶部的 **Windows** 按钮创建 Windows 对话，**WSL** 按钮在当前 Linux 项目创建对话。两个按钮共占原来一行新建按钮的高度。

在“工作区”标题右侧点击 **新建 WSL 工作区** 的文件夹加号，选择发行版、用户和目录。可以直接输入已有目录，也可以点击 **浏览…** 进入 Linux 文件夹选择器。在选择器中点击 **新建文件夹**，输入名称后创建，再点击 **选择此文件夹**。

工作区创建后会出现在原生列表中。创建目录不会覆盖已有同名文件夹；重命名工作区只改显示名称，文件夹路径保持原样。

## 与原生工作区一致的操作

| 操作 | WSL 中的行为 |
| --- | --- |
| 展开、收起、更多会话 | 使用 DSH 原生列表和相同行高、文件夹图标 |
| 拖动工作区 | 调整列表位置，支持与 Windows 工作区交错排列 |
| 工作区菜单 → 重命名 | 修改 Linux 的工作区名称 |
| 工作区菜单 → 删除工作区 | 移除 Linux 的工作区登记，保留目录和会话记录；使用原生确认框 |
| 工作区右侧新建按钮 | 在该 Linux 工作区打开新对话，沿用原生空会话复用规则 |
| 对话菜单 | 置顶、取消置顶、重命名、创建分支、归档、恢复及交接工作 |
| 拖动对话 | 按原生规则调整列表顺序；运行位置和文件目录不变 |
| 视图选项 | 工作区、目录树、平铺、手动／更新时间排序、归档显示 |
| 搜索 | 标题与项目过滤；已连接环境支持官方会话内容搜索 |

联合顺序保存在当前 Windows DSH 界面中。WSL 工作区之间的相对顺序也写回 Linux。拖动工作区是列表排序，不是跨系统搬运项目文件。

Windows 行保留原有插件提供的菜单。WSL 行提供上述内置操作；第三方插件的自定义行操作仍由其所属环境实现。Linux 插件管理入口位于 WSL 对话顶部的 **Linux 配置**。

“工作区”标题右侧的小切换按钮可以改用紧凑对话列表，再次点击即可返回原生列表。紧凑列表继续提供搜索、环境筛选和归档显示。

## 把工作交给另一环境

1. 在来源对话的菜单中选择 **交接工作…**。查看 WSL 对话时，也可以点击顶部的 **交接工作**。
2. 选择另一环境，指定已有对话，或选择目标工作区的新对话入口。
3. 填写已经完成的工作、相关文件和下一步要求。需要上下文时点击 **带入最近对话**，检查并编辑摘录。
4. 展开 **预览完整交接内容**，核对来源、目录和说明。
5. 选择 **放入目标输入框** 或 **发送交接**。

放入输入框只准备草稿，不调用模型。目标已有草稿、附件或正在提交时，会保留原内容并提示处理。新对话入口沿用 DSH 对空会话的复用规则。

交接草稿写入 DSH 原生持久化状态，刷新后仍会保留。

发送交接会调用目标环境配置的模型。目标正在工作时，交接进入后续队列；来源任务继续运行。要把成果交回来，在目标对话再次选择交接，选中原来的来源对话即可。

交接只在点击后执行，不会自动循环对话或持续转发消息。同一次交接不会因重复点击再次提交。若连接中断、发送结果不明，先检查目标会话，插件不会自动重发。

## 上下文和文件

最近对话摘录最多包含 8 条已提交的用户／助手文字消息，上限为 18,000 字符。工具输出、推理内容和附件不自动带入；最终交接内容上限为 24,000 字符。工作说明和摘录都可以在发送前编辑。

交接附上来源环境、对话 ID 和工作目录。Windows 盘符路径同时给出默认挂载设置下的 `/mnt/<盘符>/...` 形式；Linux 路径给出 `\\wsl.localhost\<发行版>\...` 形式。自定义挂载路径时，需要在说明中填写实际路径。

文件保持原位置。两边操作同一项目时，可直接使用共享可访问路径；需要单独副本时，明确使用插件的复制工具。交接不会自动复制整个项目，也不会合并两个会话的完整历史。
